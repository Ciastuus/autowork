# AutoWork LIVE — GitHub Pages

Publiczny podgląd HTML (dane demonstracyjne). Aby uruchomić przez GitHub:

1. Utwórz repozytorium, np. `autowork-live` (do GitHub Pages na koncie Free wybierz **Public**).
2. Przenieś **zawartość** tego folderu do głównego katalogu repozytorium.
3. GitHub → Settings → Pages → Deploy from branch → main / (root) → Save.
4. Po wdrożeniu otwórz `https://TWOJ_LOGIN.github.io/autowork-live/`.

Ta strona działa w **trybie demonstracyjnym**: GitHub Pages to hosting statyczny,
nie odczytuje prywatnych plików komputera. Możesz otworzyć **ten sam panel na żywo**
spoza domu przez Tailscale: zainstaluj Tailscale na komputerze z GTA i telefonie,
uruchom lokalny `start_phone.bat` i wejdź na `http://IP_TAILSCALE_PC:8765`.
Nie przekierowuj portu z internetu i nie umieszczaj prywatnych logów w repo.
